# Mes BEX

Application d'entraînement aux banques d'exemplaires (BEX) d'histoire-géographie, pour des élèves de collège.

Site : https://mhofstoetter-pixel.github.io/mes-bex/

Ce dépôt ne contient que le site construit (fichiers statiques). La progression des élèves reste sur leur appareil : pas de compte, aucune donnée envoyée.
